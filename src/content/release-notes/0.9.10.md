## Dictionary fix

- **New entries show up right away.** Words and phrases you add to the Dictionary (and to Snippets and Styles) now appear in the list as soon as you add them, instead of only after reopening the app.
- **After an update on Mac,** if Voxflow keeps asking for Accessibility, quit it, run `tccutil reset Accessibility com.voxflow.app` in Terminal, and allow it again.
